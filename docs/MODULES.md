## Интеграция модулей

### News → Notifications
- При создании новой новости отправлять уведомления подписанным пользователям

### Torrents → Notifications
- При завершении загрузки отправлять уведомление пользователю

### Core → All
- Все модули используют базовые утилиты из Core
- Общие permission классы из Core
